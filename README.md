# 🗳️ Online Voting System

A secure and scalable **online voting platform** built with **Flask** and **MongoDB**.  
It supports voter authentication, real-time vote tracking, admin management, and ensures election integrity.

---

## 🚀 Features
- 🔒 **Secure Authentication**: Session-based login for voters and admin.
- 📊 **Real-time Vote Tracking**: Automatic logging and candidate-wise counting.
- 🛡️ **Election Integrity**: HTTPS-enabled secure connections.
- 📂 **Auditability**: Election history archived with voter activity logs.
- 🖥️ **Admin Dashboard**: Manage voters, candidates, and view live results.

---

## 🛠️ Tech Stack
- **Backend**: Flask (Python)
- **Database**: MongoDB
- **Frontend**: HTML, CSS (Jinja2 Templates)
- **Deployment**: Docker (containerized)
